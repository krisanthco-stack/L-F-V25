LIBRETA DE FISCALIZACIÓN V22.0.3

1. Cree un repositorio público nuevo en GitHub.
2. Extraiga este ZIP en su computadora.
3. Suba TODOS los archivos directamente a la raíz del repositorio, no dentro de una carpeta.
4. En GitHub abra Settings > Pages.
5. En Build and deployment seleccione Deploy from a branch.
6. Seleccione main y /(root), luego Save.
7. Espere a que GitHub muestre el enlace publicado.
8. Abra únicamente la dirección Pages del repositorio nuevo.

Esta revisión usa una caché nueva y activa la actualización inmediatamente.

9. Esta versión protege los datos existentes cuando una actualización Excel/CSV omite columnas.

10. Base local incluye búsqueda por folio, trámite, finca o lugar y filtros desplegables dependientes por distrito y lugar.
